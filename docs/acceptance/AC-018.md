## AC-018-B01 — Keep delivery and discovery on the selected publication

- Family: `AC-018`
- Type: `boundary`
- Profiles: `website`
- Requirements: `CMS-005`, `CMS-007`, `CMS-012`
- Layers: `real-provider-integration`, `api-contract`, `ui`
- Security dependencies: `AC-003`, `AC-004`, `AC-031`

### Profile scope

- `website`: W Razor delivery for one site/culture with prequalified aliases and media decisions, installed renderers and discovery derived from the active publication. Host manipulation and protected-content boundaries remain AC-004/AC-031 work.

### Preconditions

- article-1 revision-1 is published at /guide; revision-2 changes title and slug but remains a draft. The protected preview fixture is supplied by AC-003.

### Steps

1. Read /guide, canonical metadata and sitemap while creating the draft.
2. Publish revision-2 with a declared route move and inspect delivery and discovery after convergence.

### Expected outcome

- Before activation the three public outputs still describe revision-1's published route and title.
- After convergence they consistently describe revision-2; a draft save alone does not update the public projection.

### Evidence to retain

- Published/draft revision ids, response/SEO/sitemap snapshots and publication-generation timeline.

## AC-018-N01 — Refuse a release with an unavailable Razor renderer

- Family: `AC-018`
- Type: `negative`
- Profiles: `website`
- Requirements: `CMS-003`, `CMS-005`, `UI-007`
- Layers: `real-provider-integration`, `api-contract`, `ui`
- Security dependencies: `AC-003`, `AC-004`, `AC-031`

### Profile scope

- `website`: W Razor delivery for one site/culture with prequalified aliases and media decisions, installed renderers and discovery derived from the active publication. Host manipulation and protected-content boundaries remain AC-004/AC-031 work.

### Preconditions

- manifest-1 renders with installed template version 1; proposed manifest-2 requires absent template version 2.

### Steps

1. Validate the proposal and attempt activation.
2. Request the currently published page after the failure.

### Expected outcome

- Validation identifies the missing renderer and blocks activation.
- Existing delivery still uses manifest-1 and its installed renderer, with no partial template substitution.

### Evidence to retain

- Renderer dependency diagnostic, active pointer and postfailure response.

## AC-018-P01 — Render one publication through canonical and alias bindings

- Family: `AC-018`
- Type: `positive`
- Profiles: `website`
- Requirements: `CMS-005`, `CMS-007`, `CMS-009`, `CMS-012`, `UI-007`
- Layers: `real-provider-integration`, `api-contract`, `ui`
- Security dependencies: `AC-003`, `AC-004`, `AC-031`

### Profile scope

- `website`: W Razor delivery for one site/culture with prequalified aliases and media decisions, installed renderers and discovery derived from the active publication. Host manipulation and protected-content boundaries remain AC-004/AC-031 work.

### Preconditions

- One site in en-US has a canonical binding and two already qualified alias bindings. manifest-1 selects page-1 and a versioned eligible image with alt text.

### Steps

1. Request page-1 through each binding using the configured Razor renderer.
2. Inspect response content, media version, canonical metadata and sitemap entry.

### Expected outcome

- Every binding resolves the same site, culture and selected revision.
- The page uses the declared media version and the configured canonical origin; metadata and sitemap reference the selected publication.

### Evidence to retain

- Binding inventory, rendered responses, media digest and canonical/sitemap observations.

## AC-018-R01 — Rebuild Razor delivery cache from the active manifest

- Family: `AC-018`
- Type: `recovery`
- Profiles: `website`
- Requirements: `CMS-005`, `CMS-009`, `UI-007`
- Layers: `real-provider-integration`, `api-contract`, `operational-recovery`
- Security dependencies: `AC-003`, `AC-004`, `AC-031`

### Profile scope

- `website`: W Razor delivery for one site/culture with prequalified aliases and media decisions, installed renderers and discovery derived from the active publication. Host manipulation and protected-content boundaries remain AC-004/AC-031 work.

### Preconditions

- manifest-2 is active with retained schema, renderer and Files versions; derived delivery cache contains an older generation.

### Steps

1. Interrupt cache rebuild, discard only derived cache state and restart rendering.
2. Read each published route through canonical and qualified alias bindings.

### Expected outcome

- Rebuild converges to manifest-2 from authoritative data without changing publication history.
- All sampled pages and media references use one internally consistent active-manifest generation.

### Evidence to retain

- Rebuild checkpoints, authoritative hashes and route/media response comparisons.
